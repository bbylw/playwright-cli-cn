## 键盘

| 命令 | 说明 |
| --- | --- |
| `press <key>` | 按下某个键（例如 `Enter`、`ArrowLeft`、`a`） |
| `keydown <key>` | 按住某个键不放 |
| `keyup <key>` | 松开某个键 |
| `type <text>` | 逐字符向当前聚焦元素输入文本 |

### 常用按键

`Enter`, `Tab`, `Escape`, `Backspace`, `Delete`, `Space`, `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`, `Home`, `End`, `PageUp`, `PageDown`

### 组合键

```bash
playwright-cli press Control+a          # select all
playwright-cli press Control+c          # copy
playwright-cli press Control+v          # paste
playwright-cli press Shift+Tab          # focus previous
playwright-cli press Alt+Enter          # alt+enter
```

`keydown` / `keyup` 可以让修饰键在多条命令之间保持按下状态，这是 `press` 做不到的：

```bash
playwright-cli keydown Shift
playwright-cli click e5
playwright-cli click e9                 # extends the selection
playwright-cli keyup Shift
```

如果只是想在单次点击中按住修饰键，使用 `click --modifiers` 更简单 —— 参见[交互](/docs/commands/interaction)。

### 键盘导航

```bash
playwright-cli press Tab                # next field
playwright-cli press Tab                # next field
playwright-cli press ArrowDown          # navigate dropdown
playwright-cli press ArrowDown
playwright-cli press Enter              # select option
```

## 鼠标

| 命令 | 说明 |
| --- | --- |
| `mousemove <x> <y>` | 将鼠标移动到指定坐标 |
| `mousedown [button]` | 按下鼠标键（left、right、middle） |
| `mouseup [button]` | 松开鼠标键 |
| `mousewheel <dx> <dy>` | 滚动（dx 为水平方向，dy 为垂直方向） |

坐标是相对于视口的 CSS 像素。`snapshot --boxes` 会以同一坐标系报告每个元素的盒子（box），这比从截图上读取位置要可靠得多。

```bash
# Click at coordinates
playwright-cli mousemove 100 200
playwright-cli mousedown
playwright-cli mouseup

# Right-click
playwright-cli mousemove 300 400
playwright-cli mousedown right
playwright-cli mouseup right

# Scroll down 500 pixels
playwright-cli mousewheel 0 500

# Scroll right 200 pixels
playwright-cli mousewheel 200 0
```

### 何时使用鼠标命令

| 场景 | 推荐做法 |
| --- | --- |
| 点击按钮、链接或表单元素 | `click`、`fill` 等基于 ref 的命令 |
| 基于 Canvas 的应用（绘图、地图） | 使用坐标调用鼠标命令 |
| 没有无障碍信息的自定义 UI 控件 | 使用坐标调用鼠标命令 |
| 需要像素级精度的拖拽交互 | 使用坐标调用鼠标命令 |

对大多数 Web 应用而言，**来自无障碍快照（accessibility snapshot）的 ref 比坐标更可靠**。只有在无障碍树没有暴露你需要的元素时，才使用鼠标命令。
